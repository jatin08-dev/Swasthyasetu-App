# Swasthyasetu-App
Swastyasetu is a smart hospital finder app that helps users quickly find nearby hospitals, including government, private, and 24/7 hospitals. It provides hospital details, location, contact information, specialists, login/signup, and an AI chatbot for easy healthcare assistance.
📱 Android/Flutter app source code
🔐 Login & Signup
🏥 Government / Private / 24×7 hospital categories
📍 Location-based hospital search
🤖 AI chatbot module
🔥 Firebase authentication & database
🚑 Emergency/ambulance section
🩸 Blood bank information
